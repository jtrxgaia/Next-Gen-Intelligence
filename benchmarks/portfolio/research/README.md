## Dated learning and implementation evidence

The [October 26 core review](../engineering/core-evidence.md) inspected the implemented neuro-symbolic components and their application connections. Three selected private suites passed **47/47 tests**. A new synthetic probe passed **200/200 exact cases** with values absent from three demonstrations, and retained those results after state restoration. These are component-level, within-family observations.

The separate [October 25 training record](../../results/2026-10-25-ai-training-review.json) records custom-model initialization from scratch, **34/34 training-exposed examples**, and **eight consistent restart outputs**. Training fit, symbolic transfer, and broad neural generalization are separate measurements.

The core is currently undergoing maintenance. These dated results document the reviewed implementations and experiments.
