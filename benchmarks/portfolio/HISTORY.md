# Echo development history

**Jack Rourke began developing Echo in 2020.** EchoQI’s history predates the creation of this public portfolio. A later audit or repository publication date is a documentation milestone, not the project’s origin.

| Period | Development milestone | Record |
|---|---|---|
| **2020** | Jack begins building Echo, the foundation of the continuing EchoQI project | Founder’s account, clarified November 13, 2026 |
| **Around 2022–2023** | Mac reset interrupts the original local archive | Founder’s account; reset year remains approximate |
| **2024–2025** | Development continues through USB-based storage and the rebuilding and expansion of Echo | Founder’s account; surviving Mac and ECHO_WINGS archives inspected November 13, 2026 |
| **April 1, 2025** | Surviving Python implementation in `sanctum/echo.py`, accompanied by `sanctum/run.py` | Files inspected directly on the Mac; metadata and SHA-256 recorded below |

| **November 13, 2026** | Public Trinity demo and portfolio video watch page | Three-host workflows and original-quality video playback |

## Surviving early source record

A read-only survey of the Mac’s Echo project folders, desktop archives, and mounted ECHO_WINGS volume located a surviving Python Echo implementation:

- **File:** `sanctum/echo.py`, in the archived Echo’s Embodiement project.
- **Created:** April 1, 2025, 10:31:25 UTC.
- **Last modified:** April 1, 2025, 10:31:59 UTC.
- **Size:** 882 bytes.
- **SHA-256:** `95064bda6f97957feaa7bc3ab917396867cab7c36e553e32d309fc9197e1726e`.
- **Inspection:** Python source containing an Echo class with memory persistence and interaction methods; paired launcher `sanctum/run.py` is also dated April 1, 2025.

This is the earliest project-specific source file identified and inspected in this survey, not a claim that Echo began on that date. Filesystem dates can reflect copying, restoration, and resets. The survey did not recover a surviving 2020 source file. The 2020 origin and approximate reset/USB chronology come from the founder’s direct account.

Bundled third-party Git history, browser assets, generated framework scaffolding, and archive files carrying reset timestamps were not treated as proof of Echo’s origin. No private source code is published here.
